# Job Solution Pokhara

A weekend project to build a local job platform for Pokhara city.

## Current Assets
- Facebook Page: 4,000 followers

## Project Goals
1. Create a job listing website for Pokhara
2. Automate job posting and management processes
3. Connect local employers with job seekers
4. Grow the platform organically using existing Facebook presence

## Phases

### Phase 1: Foundation
- [ ] Define target audience (job seekers vs employers)
- [ ] Research local job market in Pokhara
- [ ] Analyze competitors (if any)
- [ ] Define unique value proposition

### Phase 2: Manual MVP
- [ ] Start posting jobs manually on Facebook
- [ ] Create simple Google Form for employers to submit jobs
- [ ] Build engagement and understand what works

### Phase 3: Website Development
- [ ] Choose tech stack
- [ ] Build simple job listing site
- [ ] Integrate with Facebook page

### Phase 4: Automation
- [ ] Auto-post new jobs to Facebook
- [ ] Email notifications for job seekers
- [ ] Simple admin dashboard

### Phase 5: Growth
- [ ] SEO optimization
- [ ] Paid promotions strategy
- [ ] Partnerships with local businesses/colleges
